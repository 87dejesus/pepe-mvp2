# Experiment log

Append-only. One entry per experiment: what ran, what we saw, what we decided.
Written the same week it ends, while it is still uncomfortable.

Template:

```
## YYYY-MM-DD — <name>
**Hypothesis:** H<n>
**Setup:** cohort, duration, arms, n
**Result:** the numbers, including the ones that disappoint
**Decision:** what changed as a result
**Surprise:** what we did not expect — usually the most valuable line
```
