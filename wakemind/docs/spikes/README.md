# Spikes

A spike is a **time-boxed technical question**, not a head start on the product.

Rules: one question, a deadline, a written answer in the same file. Code from a
spike is thrown away. If the box expires without an answer, stop and report —
extending a spike is how a two-day question becomes a three-week detour.
